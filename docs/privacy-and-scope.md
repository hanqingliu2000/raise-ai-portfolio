# Privacy and scope

## Provenance

This repository was created independently for portfolio use. It does not retain the private repository's Git history, issues, pull requests, source files, prompts, assets, logs, screenshots, or output artifacts. The real project remains private.

All observations are generated by arithmetic functions. Fictional notes and simulated recommendations were authored specifically for this demonstration. No actual data was anonymized, perturbed, scaled, or copied to create these examples.

The professional experience and approximate internal evaluation figures in the README were supplied by the author. They describe the private project and cannot be independently verified with this example. No internal benchmark records are included.

## Data behavior

- No telemetry, analytics, cookies, login, upload endpoint, or live AI calls.
- Review progress stays in local browser storage.
- PNG and JSON exports are downloaded directly to the user's device.
- Dependency and hosting providers may receive ordinary requests to serve the application. External source links open GitHub only when clicked.
- Do not paste confidential material into a public demonstration, even if the app currently runs locally.

## Release checks

Review every file and commit before publishing. Check source, compiled assets, comments, document metadata, screenshots, and fixtures for credentials, personal details, company paths, real observations, and internal materials. Scan all branches before later publication, not only the default branch. Do not bring private history into this repository.

No scan proves that an employer has authorized publication. Any future reuse of employer-owned code or assets requires appropriate permission; this example intentionally avoids such reuse.
